# Tell Grammar README

## Introduction
**Tell Grammar** is a part-of-speech tagging project designed to help users better understand grammar. The app allows users to write sentences and automatically identifies the part of speech for each word, making it a valuable tool for language learners and educators.

## Features
1. **Part-of-Speech Tagging**
   - Automatically identifies and labels the part of speech (e.g., noun, verb, adjective) for each word in a sentence.

2. **Interactive Sentence Input**
   - Users can input sentences directly into the app for real-time analysis.

## Technology Stack
- **Backend**: Python with NLTK library

## Prerequisites
Ensure you have the following installed:
1. **Python 3.9+**

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/UmarBelloKanwa/Tell-grammer/
   cd tell-grammar
   ```
2. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # For Linux/macOS
   venv\Scripts\activate    # For Windows
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the Python script:
   ```bash
   python tell_grammar.py
   ```

## Usage
1. **Input a Sentence**: Run the script and input a sentence when prompted.
2. **View Results**: The app will display each word along with its corresponding part of speech.
3. **Learn Grammar**: Use the tagging results to understand the grammatical structure of your sentences.

## Key Functionalities
- Real-time part-of-speech tagging.
- Support for various sentence structures.
